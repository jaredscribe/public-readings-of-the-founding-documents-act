# Letters as sent

The Constitution Day letters to congressional leaders and to the President, **exactly as
each office received them** — one file per letter, named by the date it was sent and
the office it went to.

The current text of each letter is published, and continues to be revised, at
<https://declareindependence.net/open-letters>. These files are the record, and they do
not change: a letter improved after it went out is improved on the site, never here.
Where a sent letter carried an error, the error is left in and noted above the letter.
A campaign that silently improved its own record would be making the same move it asks
Congress to stop making.

Each file opens with how and when the letter was sent, then the letter itself. Left out
of every copy: the short preface that introduced an emailed letter to the staffer it
was routed through, and all recipients' email addresses.
